# MaDenMusic 2.8

Полный архив содержит исходные песни, обложки, тексты и значки. Содержимое архива разместите в папке публикации GitHub Pages, сохранив структуру каталогов. ZIP загружать на сайт вместо распакованных файлов не нужно.

Для обновления существующего сайта замените index.html, style.css, app.js и добавьте sw.js. songs.js и manifest.json приложены без изменений. Папки songs, covers, lyrics и значки сохранены без изменений.

Откройте опубликованный сайт по HTTPS с интернетом и дождитесь первой загрузки. После установки Service Worker приложение и каталог запускаются офлайн. Просмотренные обложки и тексты сохраняются по мере загрузки (до 180 файлов). MP3 автоматически не скачиваются для офлайн-прослушивания; для музыки нужен интернет. Браузер может удалить хранилище при нехватке места.

Кнопка «Обновить MaDenMusic» проверяет SW, дожидается загрузки новой оболочки и активирует её перед перезагрузкой. При сбое установки остаётся предыдущая рабочая оболочка. Любимые песни и тема сохраняются. Кэши других приложений не удаляются.

При следующих выпусках меняйте BUILD в sw.js вместе с файлами оболочки. Загружайте весь выпуск одним коммитом. Иначе браузер не обнаружит изменение версии оболочки.

Проверено локально в Microsoft Edge: первый запуск SW, офлайн-перезагрузка, успешное обновление, отказ обновления при HTTP 503, сохранение избранного и чужого кэша, каталог, Люмейя, обе темы и Telegram. JavaScript проверен на синтаксис; HTML — на структуру тегов, CSS — на структуру и отображение в браузере. songs.js и вся логика плеера после блока обновления совпадают с исходниками. На реальном iPhone и опубликованном GitHub Pages эта сборка пока не проверялась.

Справочник API обновления: https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/update
