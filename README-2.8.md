# MaDenMusic 2.8 — альбом «Мой выбор — это ты»

Добавлен альбом из пяти аранжировок с описаниями стилей. Бейдж «Новинка» появляется только у MJ Style и действует по существующему 14-дневному правилу.

## MP3 нового альбома

Разместите файлы в папке `songs/` рядом с `songs.js`:

- `songs/my-choice-remix.mp3` — Remix
- `songs/my-choice-electronic.mp3` — Electronic
- `songs/my-choice-french-touch.mp3` — French Touch
- `songs/my-choice-rock-style.mp3` — Rock Style
- `songs/my-choice-mj-style.mp3` — MJ Style

MP3 не включены в архив. Новые записи пока имеют `available: false` и показываются как «Скоро будет». После помещения соответствующего файла измените это значение на `true`. Если используете другие имена, поправьте поле `audio` у нужной записи в `songs.js`.

## Установка

Распакуйте файлы в папку сайта с заменой одноимённых файлов. Существующие папки `songs/`, `covers/`, `lyrics/` и значки сохраните. Новая обложка пока использует `covers/Remixes.png`; при наличии отдельной обложки поменяйте путь для альбома в `albumMeta` в `songs.js`.

Версия Service Worker обновлена для загрузки новой оболочки. После публикации откройте сайт онлайн один раз.
