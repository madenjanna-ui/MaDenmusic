# MaDenMusic — альбомная версия

Основа: текущий рабочий репозиторий MaDenmusic-main(2).

## Альбомы
1. Моя
2. Новый
3. Мой ангел
4. Новая веха
5. Remixes
6. Люмейя

## Что изменено
- Альбомная навигация и карточки альбомов.
- Страница альбома с доступными и будущими композициями.
- `available: false` показывается как «Скоро будет» и не попадает в воспроизведение.
- Мини-плеер остаётся после закрытия большого плеера.
- Мини-плеер содержит предыдущий/пауза/следующий.
- Shuffle и Repeat.
- Media Session API: play/pause/next/previous/seek + метаданные и обложка.
- Сохранены реальные MP3 и текущий songs.js из рабочего архива.
- Люмейя оформлена как отдельная приветственная страница проекта с входом в мир и блоком языка звёзд и сердца.

## Обложки альбомов
Пользователь добавляет свои актуальные обложки в `covers/` согласно путям `albumMeta` в `songs.js`:
- `covers/moya.png`
- `covers/novyi.png`
- `covers/My angel.PNG`
- `covers/Novaya veha.png`
- `covers/Remixes.png`
- `covers/album_lumeya.jpeg`
