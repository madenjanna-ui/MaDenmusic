# MaDenMusic — последние изменения

В комплекте: index.html, app.js, style.css и папка lyrics/.
MP3 и songs.js сюда не включены — оставьте их из текущего проекта.

## Тексты
app.js сначала ищет lyrics/<id>.txt. Если файла нет, используется резервный lyrics из songs.js.
Чтобы заменить текст песни, просто отредактируйте соответствующий TXT.

## Управление плеером
1) Предыдущая / Play / Следующая
2) Shuffle / Repeat
3) Кнопка «Слова»

## Люмейя
Сначала открывается приветственная страница. Песни и словарь появляются только после «Войти в Люмейю». Слова словаря раскрываются по нажатию.
